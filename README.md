# Regolith

Scoop the dust, sinter the feedstock, print a home, and cut the cord to Earth.

**Play it online:** https://agolkar.github.io/regolith/

## About

Regolith is a 3D lunar construction driving game set in the south-polar highlands during a single four-minute surface window. You direct HELIOS-1, a robotic construction platform that scoops regolith, hauls it to a sintering plant, and feeds a rail gantry printer that builds habitat modules. The Sun sinks from 12 degrees to 4 degrees over the run, so sunlight, shadow and incoming hazards keep shifting the route you take. Reach 100 percent independence before the window closes, with the base powered and intact.

## How to play

**Goal:** Print five habitat modules to reach 100 percent independence before the four-minute window closes, keeping the base powered and intact.

| Keys | Action |
| --- | --- |
| W A S D / arrows | Drive |
| Shift | Boost |
| Space | Scoop |
| Enter | Print module |
| 1 dome / 2 solar / 3 life support | Select module |
| R | Restart |

- Hold Space within 3 m of a deposit and below 2 m/s to load the hopper; the plant auto-dumps when you are within 4 m.
- A print needs at least 300 kg feedstock in the plant and takes 18 s; head out for the next load while it runs.
- Watch the Sun: the sunlit work area shrinks as it sinks, and crater floors and long shadows stop battery recharge.
- During a solar flare, shelter inside a completed dome or the exposure drains power and integrity.
- Meteoroid target rings are fixed when they spawn, so move off the ring before impact.

## Features

- Kinematic terrain-following driving with cruise and boost speeds, slope slowdown and boulder hits that cost integrity and reset combo.
- Regolith scooping in 10 kg ticks, sintering into feedstock, and an 18 s gantry print that grows each module layer by layer.
- Five foundation pads with dome, solar and life-support modules that add independence, integrity, recharge and shelter.
- A four-minute progression from calm opening to micrometeoroid showers, two solar flares, an Earth resupply lander and a final low-Sun push.
- Photoreal lunar look with raking low sunlight, hard near-black shadows, no atmospheric haze, and saturated colour only from emissive status lights and print glow.
- Chase camera with turn lag, printer pull-back, boulder and impact shake, and a low horizon that keeps the Sun and the Earth in frame.
- Sparse ambient synth score with no percussion, vacuum-appropriate ambience, and radio voice lines for scoop, feedstock, print, flare, low power and mission end.
- HUD showing independence, timer, power and integrity bars, hopper and feedstock totals, combo multiplier and the selected module.

## How this game was made

The idea comes from a voice note by Max; the setting and look were fixed in advance by a short brief: a photorealistic lunar surface. Everything after that was done by an automated pipeline running on local AI models on a Mac Studio (M3 Ultra, 256 GB), with no human intervention between the voice note and this repository, in about 5.9 hours:

| Stage | Model or tool |
|---|---|
| Transcription of the voice note | stt-server (Whisper large-v3, MLX) |
| Concept, game design, design review, code, fixes and gameplay reviews | deepseek-v4.1-flash |
| Images: key art, textures, sprites (7) | Qwen-Image 2.1 (sdcli) |
| Video cutscenes and music (3 clips, 1 loops) | LTX-2.5 (ltx-2-mlx) |
| Voice lines (10) | macOS text to speech (Daniel) |
| Visual checks of images and screenshots | deepseek-v4.1-flash, Qwen3.8-27B-8bit |
| Testing | headless Chromium driven by a random-input bot (Playwright) |

The pipeline itself (orchestration, prompts, static checks, the test bot and a small reusable engine layer for rendering, input, audio, effects and interface in `src/engine/`) was written in advance by Claude (Anthropic) for this experiment. The game-specific design, the code in `src/game/` and all assets were generated by the local models. `docs/build-report.md` records every step, check and fix.

## Running it

The game is a static web page. From this folder run `python3 -m http.server 8000` and open http://localhost:8000. Opening index.html directly from the file system does not work, because browsers block ES modules there.
